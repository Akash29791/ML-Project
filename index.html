About AQUA-SENSE

A software-based water quality assessment application that accepts manually entered readings, checks configured parameter limits, displays a preliminary screening result and maintains sample history.

Technologies: HTML, CSS, JavaScript and browser local storage.

Note: This application does not use physical sensors. Actual drinking-water safety must be confirmed through appropriate certified laboratory testing.
